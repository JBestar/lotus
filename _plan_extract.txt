4.  필요한 기능 
로투스홀짝은  12판에 한번씩(가끔 13판을 할때도 있음) 패를 섞습니다.  
 밑에 화면에 보시면  패를섞을때를 우리는 1판으로 정합니다. (1판이 12판이 될수도 
있습니다.-히든카드를 항상 먼저 꺼내고 패를 섞기 때문에) 

--- PAGE 4 ---
그래서 판수정보가 중요하기 때문에  1판전에  표시를 하던지 혹은 1판의 결과가 나오고 표시를 
하던지 해서  표시가 되어야 됩니다 .(화면상으로는 어디가 1판인지 알수 없습니다. ) 
 
 
게임 셋팅 방법 
1) 단계마무리--- 셔플 주기 내 '단계 마무리(신규 진입 제한)' 로직 
➢ 기능 개요 
• 
목적: 셔플 주기(1~12판, 간혹 13판) 후반부에 새로운 베팅 사이클(1단계)에 진입하는 것을 
막고, 이미 진행 중인 마틴(2단계 이상)만 종료한 뒤 다음 셔플까지 대기하는 기능. 
• 
판수 카운팅 기준: 패를 새로 섞는(셔플) 시점을 1판으로 초기화하여 카운팅 (히든카드 오픈 
후 셔플 시점을 1판으로 간주). 
 
➢ UI / 입력 파라미터 
• 
기능 활성화 여부: is_step_finish_enabled (Boolean, 체크박스 등) 

--- PAGE 5 ---
• 
제한 기준 판수: step_finish_round (Integer, 예: 8 입력 시 8판까지만 신규 진입 허용) 
• 
UI 라벨 권장안: [ ] ( N )판 단계 마무리 (툴팁: N판 초과 시 신규 1단계 진입을 중단하고, 
진행 중인 단계만 마무리합니다.) 
 
➢ 핵심 비즈니스 로직 (상태 기반 분기) 
매 회차(Round) 베팅 판단 시점마다 현재 봇의 베팅 단계(current_step)와 현재 판수(current_round)를 
비교하여 베팅 여부를 결정합니다. 
① 신규 진입 상태 (current_step == 1) 
• 
조건: current_round <= step_finish_round 
o 
True: 패턴 조건 충족 시 정상 베팅 진행 
o 
False (설정 판수 초과): 패턴 조건이 충족되어도 베팅 스킵 (대기) 
② 마틴 진행 중 상태 (current_step > 1) 
• 
조건: current_round와 무관하게 무조건 베팅 진행 
o 
설정한 판수(예: 8판)를 넘겼더라도 current_step이 1로 초기화될 때까지(적중 또는 
최고 단계 도달 시까지) 계속 베팅 수행. 
o 
적중하여 current_step이 1이 되는 순간, 위 ①번 조건(current_round <= 
step_finish_round)에 걸려 이후 셔플 전까지 자동 휴식. 
➢ 의사코드 (Pseudocode) 
python 
# 변수 설명 
# current_round: 현재 셔플 주기 내 진행 판수 (1 ~ 13) 
# current_step: 현재 마틴 단계 (1단계 = 신규 진입, 2단계 이상 = 마틴 진행 중) 

--- PAGE 6 ---
# step_finish_round: 사용자 설정 마감 판수 (예: 8) 
# is_step_finish_enabled: 단계 마무리 기능 사용 여부 
 
def can_place_bet(current_round, current_step, step_finish_round, is_step_finish_enabled): 
    # 기능이 꺼져 있으면 항상 베팅 가능 
    if not is_step_finish_enabled: 
        return True 
 
    # 이미 2단계 이상 마틴이 진행 중이라면 판수 제한 없이 마무리할 때까지 베팅 허용 
    if current_step > 1: 
        return True 
 
    # 1단계(신규 진입)인 경우, 설정한 판수 이하일 때만 베팅 허용 
    if current_step == 1: 
        if current_round <= step_finish_round: 
            return True 
        else: 
            return False 
코드를 사용할 때는 주의가 필요합니다.
